Help center

Find answers about using VEX AI, signing in, and getting help when something goes wrong.

Account & sign-in

Create an account with your email and password, or use Google sign-in when it is enabled. If email confirmation is requested, open the confirmation email before logging in.

Chat with VEX

Type a question in the message box and press Enter or the send button. Be specific about what you need. Verify important information because AI responses can be incorrect.

Something broken?

Start with the troubleshooting guide. If an error appears, note its exact wording and the device and browser you use.

Privacy & safety

Learn how account authentication and AI replies work on our privacy page. Never put passwords, authentication links, or API keys into a chat.

Before reporting a problem

  • Describe what you were trying to do.
  • Include the exact error text, if any.
  • Include your browser and device type.
  • Never include passwords, access tokens, or private API keys.
